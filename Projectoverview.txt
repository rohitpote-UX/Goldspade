4. DESIGN SYSTEM & DUAL THEME ARCHITECTURE
--------------------------------------------------------------------------------
The website implements a Light / Dark theme system controlled via CSS variables 
and Tailwind's `darkMode: ["class", '[data-theme="dark"]']` strategy.

A. Theme Tokens (`globals.css`):
   - Light Theme (Baseline):
     - Canvas Background:      #F5F5F3 (Warm off-white)
     - Primary Text:           #171515 (Editorial off-black)
     - Secondary Text:         #555555 (Mid gray)
     - Editorial Border:       #DCDCD8 (Subtle outline)
     - Mint Accent:            #73F3C5 (Signature Goldspade mint)
     - Card Background:        #FFFFFF (Pure white surface)
   - Dark Theme:
     - Canvas Background:      #0B0B0B (Deep pitch black)
     - Primary Text:           #F5F5F2 (Warm white)
     - Secondary Text:         #A8AAA6 (Soft gray)
     - Editorial Border:       rgba(255, 255, 255, 0.12)
     - Card Background:        #121212 (Elevated dark card surface)

B. Anti-Flicker Script (`app/layout.tsx`):
   To prevent Flash of Unstyled Theme (FOUT) on first paint, an inline IIFE runs 
   synchronously inside `<head>` before render:
   ```javascript
   (function() {
     try {
       var theme = localStorage.getItem('goldspade-theme');
       if (theme === 'dark') {
         document.documentElement.setAttribute('data-theme', 'dark');
       } else {
         document.documentElement.setAttribute('data-theme', 'light');
       }
     } catch (e) {}
   })();
   ```

C. Theme Transitions:
   Smooth 400ms CSS transitions (`cubic-bezier(0.16, 1, 0.3, 1)`) are configured 
   for `background-color`, `color`, `border-color`, and `box-shadow` across all 
   key UI surfaces (`header`, `footer`, `main`, `section`, `nav`, `button`, `input`).


5. MOTION & SMOOTH SCROLLING ENGINE
--------------------------------------------------------------------------------
A. Lenis Inertia Scroll:
   `SmoothScrollProvider.tsx` initializes Lenis with smooth wheel scrolling 
   (`duration: 1.2`, `wheelMultiplier: 1.0`).

B. GSAP Ticker Synchronization:
   Lenis animation frame loop is connected directly into the GSAP ticker:
   ```typescript
   lenis.on("scroll", ScrollTrigger.update);
   const updateRaf = (time: number) => { lenis.raf(time * 1000); };
   gsap.ticker.add(updateRaf);
   gsap.ticker.lagSmoothing(0);
   ```

C. SSR Safety Guards:
   Every module importing `ScrollTrigger` wraps plugin registration in a window 
   check to guarantee server components compile safely in Node.js:
   ```typescript
   if (typeof window !== "undefined") {
     gsap.registerPlugin(ScrollTrigger);
   }
   ```

D. Deterministic Route Navigation Reset:
   Whenever Next.js App Router navigates between routes, `SmoothScrollProvider` 
   executes a route change listener (`usePathname`):
   ```typescript
   useEffect(() => {
     if (typeof window !== "undefined") {
       lenisRef.current?.scrollTo(0, { immediate: true });
       ScrollTrigger.refresh();
     }
   }, [pathname]);
   ```

7. GITAPATH BRAND-BUILDING VIDEO ENGINE (`GitaPathVideoCard.tsx`)
--------------------------------------------------------------------------------
The GitaPath visual card on the Home Page hero section (`HeroSection.tsx`) features 
a custom 4-stage cinematic montage loop engine:

- Stage 01: `BRAND FOUNDATION & IDENTITY` (Logo mark & design system exploration)
- Stage 02: `SCRIPTURE & READING INTERFACE` (Mobile app reading UX detail)
- Stage 03: `ANCIENT WISDOM → DIGITAL ARCHITECTURE` (Temple architecture blending to laptop interface)
- Stage 04: `CRAFTSMANSHIP & SYSTEM ENGINEERING` (Engineering & building status)

- Viewport Optimization: Uses `IntersectionObserver` to pause frame loop intervals when scrolled out of view, saving GPU resources.

- Status Pill: `GITAPATH · BUILDING` with a pulsing mint dot indicator.

   the message field.
